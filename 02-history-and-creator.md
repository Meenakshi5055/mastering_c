**Who created C, and where?**

C was created by Dennis Ritchie, a computer scientist working at Bell Labs (part of AT&T) in the United States. He developed it between 1969 and 1973.

**With whom, and why?**

Dennis Ritchie worked closely with Ken Thompson, who had already built an earlier, simpler language called "B". At the time, Thompson and Ritchie were building an operating system called Unix, and B wasn't powerful enough for the job — it couldn't handle different data types well and was too limited for serious system-level work. So Ritchie extended and improved B into a new language, which he called C (simply the next letter after B).

**What was C first used for?**

The very first major use of C was to rewrite the Unix operating system itself. Before C, Unix was written in assembly language, which is extremely hard to read, write, and move between different computers. Rewriting Unix in C made it portable — meaning the same Unix code could now run on many different types of computers with only small changes. This portability is one of the biggest reasons C became so successful.

**How C evolved over time:**

- 1972–1973: Original C created at Bell Labs, used to build Unix.
- 1978: Ritchie and Brian Kernighan published a book called "The C Programming Language." This version of the language became known as "K&R C" (Kernighan & Ritchie C), and for years it was the unofficial standard.
- 1989/1990: C was officially standardized by ANSI (American National Standards Institute) and ISO (International Organization for Standardization). This version is called ANSI C or C89/C90.
- 1999: A newer standard, C99, added useful features like better comments, new data types, and improvements for writing cleaner code.
- 2011: C11 added support for multi-threading (running multiple tasks at once) and better handling of Unicode text.
- 2017 and 2023: C17 and C23 brought further small fixes and modern improvements, keeping C relevant today.

**Where is C used today?**

Even though C is over 50 years old, it is still one of the most widely used languages in the world:
- Operating systems — parts of Windows, Linux, and macOS are written in C.
- Embedded systems — the small computers inside microwaves, cars, medical devices, and smart appliances.
- Databases — systems like MySQL are built using C.
- Other programming languages — C++, Java, Python, and many others were either built using C or borrowed heavily from its design.

**C is often called the "mother language" of programming because so many modern languages trace their roots back to it.**
