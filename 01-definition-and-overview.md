## Topic 1 - Introduction and Overview 
**What is C?**

C is a general-purpose, procedural programming language. "Procedural" means writing a program as a sequence of steps (procedures/functions) that run one after another. It is designed to be concise, compile directly to machine code, portable  and provide low-level access to memory.


*C lets you control the computer's memory and hardware very directly, which is why it's often called a "middle-level" language (more on that in subtopic 3).*

**Learning objectives:**

* Understand what C is and where it's used.
* Know the core characteristics that distinguish C from higher-level languages.
* See a minimal example and know how to compile a simple program.

**Why does C matter?**

- It's the foundation many other languages (C++, Java, Python's interpreter, etc.) are built on or inspired by.
- Operating systems (Linux kernel), embedded systems, and performance-critical software are still written in C.
- Learning C teaches you how computers actually work — memory, pointers, compilation — in a way higher-level languages hide from you.

**Key characteristics of C:**

- Compiled language: source (.c) is translated into machine code by a compiler (e.g., gcc/clang).
- Procedural Language: code follows a step-by-step sequence of instructions.
- Statically typed (you must declare a variable's type)
- Fast and Efficient: compiles directly into binary executable code for maximum speed.
- Gives direct access to memory (via pointers)
- Small core language, but a rich standard library
- Middle-level language: combines human-readable structure with direct hardware manipulation capabilities.
- Case-sensitive; statements end with semicolons.
