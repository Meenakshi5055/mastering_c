# Module 01: Introduction & Environment Setup

Welcome to Module 01! This module builds the foundation for your C learning journey. You will learn what C is, why it remains important, how programming languages relate to hardware, and how to write and run your first C program.

---

## 📌 Module Overview

**Estimated time:** 20–30 minutes

### What you will learn

- What C is and where it is used
- The history of C and its relationship with Unix
- The difference between low-level and high-level languages
- The main advantages and limitations of C
- How algorithms, pseudocode, and flowcharts help solve problems
- How to install a compiler and run a simple C program

### Why this matters

C is used in operating systems, embedded systems, compilers, databases, and other performance-critical software. Learning C also introduces important computer science concepts such as compilation, memory, pointers, and data representation.

## 📚 Topics

1. [Definition & Overview](./01-definition-and-overview.md) — What C is and when to use it.
2. [History & Creator](./02-history-and-creator.md) — Who created C and its major milestones.
3. [Computer Language Levels](./03-language-levels.md) — Low-level, assembly, and high-level languages.
4. [Advantages & Disadvantages](./04-advantages-disadvantages.md) — The strengths and trade-offs of C.
5. [Logic Building](./05-logic-building.md) — Algorithms, flowcharts, and pseudocode.
6. [Compiler Setup](./06-compiler-setup.md) — Install a compiler and run Hello World.

## ✅ Suggested Learning Flow

1. Learn what C is and why it is still relevant.
2. Explore its history and place in the programming-language hierarchy.
3. Understand its strengths and trade-offs.
4. Practice planning solutions before writing code.
5. Set up a compiler and run your first program.

## 🎯 Module Outcomes

By the end of this module, you should be able to:

- explain what C is in your own words
- describe why C is used for systems and embedded programming
- distinguish between low-level and high-level languages
- plan a simple solution using pseudocode or a flowchart
- compile and run a basic C program
