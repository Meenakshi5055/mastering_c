> Welcome to Module 01! This is the foundation of your C learning journey. In this module, you will understand what C is, why it matters, and how to set up your environment so you can start writing real programs.

## 🎯 Learning objectives

By the end of this module, you will be able to:

- Explain what C is and why it is still important today
- Describe how C relates to hardware and programming languages
- Understand the difference between low-level and high-level languages
- Recognize the strengths and trade-offs of C
- Use algorithms, pseudocode, and flowcharts to plan solutions
- Install a compiler and run your first C program

## 🎁 What you will gain

After completing this module, you will be able to:

- Understand why C is so widely used in operating systems, embedded systems, and compilers
- Read beginner-level C concepts without feeling overwhelmed
- Set up a working C environment on your computer
- Write and run a simple program with confidence
- Build the mental model needed before moving into more advanced topics like variables, loops, functions, and pointers

## ✅ Before you start

You do not need to know advanced programming yet. You only need:

- Basic computer literacy
- A willingness to practice
- Patience while learning new concepts

If you are completely new to programming, this module is exactly where you should begin.

## 🧭 Suggested learning flow

Follow this order:

1. Learn what C is and why it still matters.
2. Understand the history and place of C in the programming world.
3. Compare C with other languages and learn its trade-offs.
4. Practice planning before writing code.
5. Install a compiler and run your first program.

> 💡 This is the foundation module. If the basics are clear here, the rest of the course will become much smoother.

## ❓ Common beginner doubts

### 1. Why should I learn C when there are easier languages?
C teaches you how software works at a deeper level. It helps you understand memory, compilation, logic, and how programming languages operate internally.

### 2. Do I need a computer science degree to learn C?
No. You can begin with the basics and learn step by step. This repository is designed for beginners.

### 3. What if I do not understand the theory at first?
That is normal. Programming becomes clearer when you combine theory with practice. Read the topic, then try the example in your editor.

### 4. What is the most important part of this module?
The most important part is understanding the foundation: C is compiled, structured, and logic-driven. Once that is clear, later topics become easier.

### 5. What happens if I skip the setup part?
You will not be able to run programs properly. The setup section is important because it makes your learning practical.

## 🧪 Module checkpoint

Before moving to the next module, ask yourself:

- What is C and where is it used?
- Why is C considered important in system programming?
- What is the difference between low-level and high-level languages?
- Why do we need a compiler?
- What does the `main()` function do?
- What is the purpose of `printf()`?

If you can answer these confidently, you are ready to move forward.

## 🌟 Final takeaway

This module is not about memorizing everything at once. It is about building a clear understanding of C as a language, how it is used, and how to start coding with confidence.

C may look strict at first, but once the rules are understood, it becomes much easier to reason about code and fix errors.
