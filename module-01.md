> 👋 Welcome to **Module 01** — the starting point of your C programming journey! Here you will learn what C is, why it is still important, how programming languages work, and how to run your first program.

## 🎯 Learning objectives

By the end of this module, you will be able to:

- Explain what C is and why it is still important today
- Describe how C relates to hardware and programming languages
- Understand the difference between low-level and high-level languages
- Recognize the strengths and trade-offs of C
- Use algorithms, pseudocode, and flowcharts to plan solutions
- Install a compiler and run your first C program

## 🎁 What will you gain?

After completing this module, you will be able to:

- 🧠 Build a clear mental model of how C programs work
- ⚙️ Understand why C is used in operating systems, embedded systems, and compilers
- 💻 Set up a working C environment on your computer
- 🚀 Write and run a simple program with confidence
- 🔍 Read beginner-level C concepts without feeling overwhelmed
- 🛠️ Prepare for variables, operators, conditions, loops, functions, and pointers

## ✅ Before you start

You do not need advanced programming knowledge. You only need:

- Basic computer literacy
- A willingness to practise
- Patience and curiosity 😊

If you are completely new to programming, this is the right place to begin.

## ❓ Common beginner doubts

### 1. Why learn C when other languages are easier?

C teaches how memory, compilation, data representation, and hardware interaction work. These ideas make many other languages easier to understand later.

### 2. Do I need a computer-science degree?

No. You can learn C step by step with practice and patience.

### 3. What happens if I skip the compiler-setup topic?

You may understand the theory but will not be able to compile, run, and test your programs. Learning by running code is essential.

### 4. What happens when I use an operator?

An **operator** performs an operation on one or more values called operands. For example, `5 + 3` uses `+` to add two operands and produces `8`. You will study arithmetic, relational, logical, assignment, and other operators in later modules.

### 5. What if I use the wrong operator?

The program may produce an incorrect result, a compiler error, or unexpected behaviour. For example, `/` performs division, while `%` gives the remainder. Always check what an operator does and what type of values it accepts.

### 6. What happens if I forget a semicolon?

The compiler usually reports a syntax error. Read the error line carefully, check the line above it, add the missing `;`, and compile again.

### 7. What if my program compiles but gives the wrong answer?

That is usually a **logic error**, not a syntax error. Check your algorithm, input values, operators, conditions, and variable values step by step.

### 8. What is the difference between a compiler error and a runtime error?

A compiler error prevents the program from being built. A runtime error happens while the program is running, such as invalid memory access or division by zero.

### 9. Do I need to memorise every rule now?

No. Understand the idea, try a small example, and return to the explanation when you need it. Practice is more valuable than memorisation.
